# AI 智能选段 V1：实际验收记录

日期：2026-10-20。沿用 `codex/text-video-editor` 工作区；未提交、推送或公开本地配置。

## 实际实现

上传与自动转写沿用现有链路。新增按用户目标推荐句段的后台任务，模型仅输出真实句段 ID 与理由，后端校验、去重、按时间排序并计算时长。推荐不会直接保存方案或导出；用户应用后仍可手动修改，再调用已有保存与异步 MP4 导出。

请求接口为 `POST /media/editor/selections`，状态接口为 `GET /media/editor/selections/{id}`，当前字幕最近任务为 `GET /media/editor/selections?mediaId=...&transcriptId=...`。任务记录在 MySQL，迁移为 V5。页面关闭不取消后台工作，重开可以恢复查看，恢复的结果应用前需明确确认替换当前草稿。

长稿按最多 100 句且文字最多 12000 字符分批，尽量重叠 2 句；为保证前进，必要时减少重叠。最多 20 批，后台执行预算 8 分钟，复用既有有限模型重试及请求限流。任一批失败不显示为完整成功。未开展真实长视频效果验收。

## 原有 AI 总结的真实调用

使用已配置的硅基流动 `deepseek-ai/DeepSeek-V3.2`，官方模型列表接口确认模型存在；本轮没有更换模型供应商。对已有自制视频和已完成 ASR 文字稿提交总结任务，没有重复识别音频。

真实任务完成两轮，遥测记录 6 次模型调用：Planner 1 次、Executor 2 次、Critic 2 次、重新规划 1 次。前端实际展示总结与时间戳证据。**最终 Critic 仍未全部通过，页面保留“部分结论需要人工核验”的提示。** 这证明调用、缓存与展示链路可运行，不代表内容质量完全验收。

本机未安装 Tesseract，OCR 分支失败后使用语音文字继续；本轮不能作为画面文字理解成功的证据。遥测中的 Token 数是程序估算，未配置模型单价时成本字段为 0，不能把它当作平台实际免费或实际账单。

## 智能选段真实操作

素材是 37.320 秒自制合成课程：原创讲解文字、Windows 合成语音及课件画面。沿用此前百炼实际识别出的 8 个句段，没有导入预制推荐，也没有手工伪造模型选择。视频画面中“手工字幕”的历史页脚指素材生成过程，本次输入文字为实际 ASR。

目标为：“保留二分查找的主题介绍、前提和基本步骤，删除重录提示及演示如何剪辑的操作说明，保持原顺序。”

模型实际推荐：

| 原视频区间 | 文字与保留理由 |
| --- | --- |
| 2.920–8.620 秒 | 二分查找演示主题，提供主题介绍 |
| 9.040–11.760 秒 | 数组有序，说明前提 |
| 12.200–17.900 秒 | 比较中间元素并排除一半，说明基本步骤 |

模型返回的全部 ID 都属于当前字幕文档，后端计算的区间总长为 14.120 秒。识别稿中的正常错字仍保留，不以模型解释替换原视频台词。

![实际生成的目标、选段与理由](images/ai-smart-selection.jpg)

实际检查：

- 生成并应用推荐后、点击保存前，数据库仍为旧方案版本 1、保留 6 句，证明没有隐式保存。
- 页面连续预览从 2.920 秒附近开始，在最后保留片段结束附近停止；播放器实际推进，未以假进度替代播放。
- 用户动作保存后成为方案版本 2、保留 3 句，再通过现有导出接口生成 MP4。
- 浏览器下载真实文件并播放至结尾，播放器 `ended=true`、时长与播放位置均为 14.16 秒，`readyState=4`；FFprobe 测得 14.160 秒、H.264/AAC、1280×720。相对区间计算多约 40 毫秒，为实际媒体输出差异，未声称毫秒级剪辑精度。
- 另一个本地账号访问推荐任务返回 HTTP 404，没有泄露推荐内容。

## 验证范围与限制

后端最终完整 **159 项测试通过**，0 失败、0 错误、0 跳过；智能选段专项 20 项通过。前端完整 **76 项测试及生产构建通过**，包含任务恢复、迟到请求、会话变化、手动修改冲突、应用推荐与保存冲突。前后端独立审查通过；最终产物重启后 `/health` 为 UP，已完成的真实推荐可以恢复。

独立审查发现“删除视频后后续批次仍会调用模型”的边界问题，已补充每批及完成前的归属检查，并加入删除发生在第一批模型调用期间的回归。另为后台线程绑定独立模型调用追踪，成功、失败和提前退出均清理线程上下文，避免调用统计缺失或混入其他任务；相关回归及独立复审通过。

当前按识别句段裁剪，句间停顿会缩短。没有真人素材识别精度、完整英语对话、切点听感或长期使用效果验收。文件选择器仍受本机浏览器扩展文件权限限制，本轮复用已实际上传的视频，不能声称文件选择器端到端验收通过。没有同济回放平台接入，也没有自动配音、动作识别或无人确认的一键出片。

配置继续使用根目录被 Git 忽略的 `.env` 中的 `SILICONFLOW_API_KEY`，与已有百炼语音 Key 分开。总结和选段共用文本模型服务，无需另接视频剪辑 API；实际裁剪由后端 FFmpeg 完成。
