# 百炼统一时间轴转写 Implementation Plan

> 使用 subagent-driven-development 在当前会话执行已获用户批准的接入方案。沿用 codex/text-video-editor 工作区，保留已有未提交修改；不提交或推送，不打印密钥。

**Goal:** 上传无字幕视频后生成可剪辑句段，复用相同文字/时间供原有转写与 VideoContext 使用，完成实际 ASR→选段→导出验收。

**Architecture:** 新增百炼 Paraformer WebSocket TimedAsrProvider，沿用既有有界任务、60 秒音频块、不可变字幕版本和剪辑导出。完成的自动转写为共用来源，旧接口优先复用；保留未配置时原有流程与手动字幕。语音静音和不流畅内容保持原样，不自动生成或改写台词。

**Tech Stack:** Spring Boot/Java21、已有 OkHttp/Jackson、MySQL/MyBatis、Vue3、FFmpeg；不引入 SDK 依赖，不暴露本机存储。

**Spec:** 用户本对话已批准“上传→句段文字→总结或文字操作→导出”，模型选为北京 paraformer-realtime-v2，DASHSCOPE_API_KEY 已本地保存。

## Rulings / evidence

- 优先按服务真实断句展示，用户选择整句；首版不自动判断“有效社交”，不默认自动删除停顿。
- 总结默认理解原视频完整文字，剪辑方案只影响成片；修改台词/配音不属于本轮。
- 密钥仅 .env，调用总量先控制在自制短素材；不自动充值、公开视频或改校园接入范围。
