# 文本驱动视频编辑：设计与个人扩展范围

## 从课程回看到口播剪辑

出发点是课程回放中的两个操作：读到一句话后回看对应画面，以及跳过不想看的片段。口播视频也有相似需求：按讲解内容找到重录段落，再从成片中删除。两者都需要让文字与原视频时间轴对应起来。

本仓库在原项目的视频导入、鉴权、存储与转写基础上增加句段编辑器。当前以单个视频为单位，支持导入 SRT/VTT、点击文字定位、查看该时刻画面、保留或删除整段、连续预览、保存恢复方案和异步导出 MP4。原视频保持完整，编辑方案只记录保留哪些句段。

同济 Look 仅是需求背景与后续扩展方向，目前未接入平台登录、抓取或下载课程视频。平台网址不是直接视频文件，不能将它粘贴后必然可用写成现有能力。

## 为什么这样实现

| 选择 | 解决的问题 |
| --- | --- |
| Vue 3 与原有页面结构 | 保留既有上传、鉴权和资料库；增加编辑弹层，减少重构范围和依赖 |
| 真实时间戳与整数毫秒 | 普通转写全文不能准确裁剪；时间必须来自字幕或服务返回的分段信息，不能由模型猜测 |
| MySQL 不可变字幕版本 | 重新导入字幕后，旧方案仍能找到它原来引用的时间轴 |
| 方案版本号与条件更新 | 多个页面同时保存时明确报告冲突，避免后保存的人无声覆盖前者 |
| 原顺序区间合并 | 去重并合并相邻或重叠句段，避免重复片段；空选择可保存，但不能导出 |
| FFprobe 与 FFmpeg | 服务端探测实际时长、截图并裁剪真实媒体；统一输出 H.264/AAC，兼容无音轨视频 |
| MySQL 导出任务与专用有界线程池 | 请求快速返回任务；限制同时转码数量，保存失败状态，支持查询与重试 |
| 内容指纹与唯一约束 | 同一用户、同一素材与时间轴、相同选段复用导出任务；临时下载签名不参与指纹 |
| MinIO 稳定对象标识 | 原视频与成片分别保存；下载时先检查归属，再生成临时地址 |

## 实际遇到的困难

- **准确定位比显示全文更难。** 新增转写接口要求服务返回真实 segments；分块提取音频要保留原始时间偏移。服务未配置时明确提示导入字幕，不能把普通文本拼成假的时间轴。
- **浏览器播放有异步竞争。** 签名地址刷新、用户跳转、关闭弹层和新预览可能同时发生。用会话及请求标识丢弃迟到结果，并释放监听器、轮询和 Blob URL。
- **任务失败不能只写一条日志。** 入队拒绝、启动中断、数据库连接异常和清理异常都需留下可查询状态；条件更新保护已经成功的结果。
- **Windows 与媒体边界有真实差异。** 大量选段会超过命令行长度，因此将滤镜写入任务目录文件；FFmpeg 9 使用 `-/filter_complex` 读取。延迟开始的音轨还需保留段内静音，独立将音画首帧归零会导致声音提前。
- **本地存储空间会影响上传。** 实际遇到 MinIO 空间保护，改为通过配置使用空间充足的磁盘，没有关闭保护或清理其他项目数据。

## 当前边界

这是一版整句段编辑器，不支持任意单字删除、自由拖动重排、多轨、自动去口癖或转场。预览在原视频上跳转区间，切换处可能停顿；成片由后端重新编码生成。截图只代表所选时间的一帧，不保证是最清晰或完整的板书。

2026-10-20 已配置百炼并实际完成无字幕视频识别：37.320 秒自制合成口播返回 8 个真实句段，删除两句后导出 26.140 秒成片。此前手工字幕演示与本次真实 ASR 分开记录。真人口音、长视频精度和主观切点自然程度尚未验收，原文本大模型也仍需单独配置。最终结果、测试数字与未验证项统一见 [验证记录](text-video-editor-validation.md)，实际取舍见 [决策及面试记录](development/text-video-editor-decisions.md)。

原有视频处理、Video Agent、检索等基础来自 [Xiaoc7r/DOVideo-AI](https://github.com/Xiaoc7r/DOVideo-AI)。本仓库的新增工作与界面改进应分别说明，不将继承的基础能力描述为个人从零实现。
